# Apply Opportunity Panel

A bilingual, privacy-conscious static dashboard for two independently scored application profiles:

- Mohammad Parsian — Applied AI, NeuroAI, research engineering, and funded PhD opportunities.
- Arzoo Barahoie / Ariidoch — sustainable craft, textile art, cultural-heritage study, residencies, awards, and legitimate modeling submissions.

The public site contains 38 opportunities verified on 2026-08-29, official source links, fit scores, eligibility and visa caveats, a 90-day action plan, a full Persian report, and a standalone bilingual portfolio for Ariidoch.

Version 2 adds:

- A device-private application workspace with a seven-stage pipeline, Kanban/table views, notes, priorities, next actions, comparisons, timeline and manual opportunities.
- JSON backup/import plus CSV and iCalendar exports.
- A local AI application-kit prompt studio for targeted CVs, SOPs, cover letters, outreach emails and interview preparation; no API key or external AI request is made by the site.
- A person/path-specific readiness center with 55 checklist items, documented gaps, portfolio projects, templates, visa/payment questions and modeling-scam safeguards.
- Advanced dashboard filters, structured deadline intelligence and cross-page local readiness/tracker summaries.
- An installable PWA with offline public shell support.
- Weekly GitHub Actions link validation and a public opportunity-health report.
- A discovery radar that checks configured official job-board APIs and curated art/study feeds three times per week, scores transparent keyword evidence, excludes known opportunities, and exposes unverified leads for manual review.

Open-status and deadlines can change without notice. Recheck the official source immediately before applying or paying any fee. The repository does not contain private CV files, phone numbers, identity documents, application notes, or secrets. Tracker and checklist state are stored only in the browser's localStorage; exported backups are unencrypted and should be stored securely.
